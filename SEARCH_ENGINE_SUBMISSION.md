## 🚀 Submit to Google Search Console

### Step 1: Create/Access Google Search Console Account
1. Go to: https://search.google.com/search-console
2. Sign in with your Google account
3. Click **"Add Property"**

### Step 2: Choose Property Type
- Select **"URL prefix"**
- Enter: `https://99reset.org`
- Click **"Continue"**

### Step 3: Verify Ownership
Choose one of these verification methods:

**Option A: HTML File Upload (Easiest)**
1. Download the HTML verification file
2. Upload it to `/public/` folder in this repo
3. Deploy to Vercel
4. Click "Verify" in Search Console

**Option B: HTML Tag**
1. Copy the meta tag provided
2. Add it to `app/layout.tsx` in the `<head>` section
3. Deploy to Vercel
4. Click "Verify" in Search Console

**Option C: DNS Verification**
1. Copy the TXT record
2. Add it to your domain's DNS settings
3. Wait for DNS propagation (5-30 minutes)
4. Click "Verify" in Search Console

### Step 4: Submit Sitemap
1. Once verified, go to **"Sitemaps"** in the left menu
2. Enter: `sitemap.xml`
3. Click **"Submit"**
4. Google will begin crawling your site within 24-48 hours

### Step 5: Request Indexing for Key Pages
1. Go to **"URL Inspection"** in Search Console
2. Enter each important URL:
   - `https://99reset.org`
   - `https://99reset.org/plan`
   - `https://99reset.org/banking-reset`
   - `https://99reset.org/housing-reset`
   - `https://99reset.org/workplace-reset`
   - `https://99reset.org/wealth-reset`
3. Click **"Request Indexing"** for each
4. This forces Google to crawl these pages immediately

## 🔍 Submit to Other Search Engines

### Bing Webmaster Tools
1. Go to: https://www.bing.com/webmasters
2. Sign in with Microsoft account
3. Click **"Add Site"**
4. Enter: `https://99reset.org`
5. Verify ownership (similar to Google)
6. Submit sitemap: `https://99reset.org/sitemap.xml`

**Bonus:** Bing can import your Google Search Console data automatically!

### Yandex Webmaster (Russia)
1. Go to: https://webmaster.yandex.com
2. Add site: `https://99reset.org`
3. Verify ownership
4. Submit sitemap

### DuckDuckGo
- No submission needed! DuckDuckGo uses Bing's index
- If you submit to Bing, you're automatically in DuckDuckGo

## ⚡ Instant Indexing (Advanced)

### Google Indexing API (For Critical Updates)
1. Go to: https://console.cloud.google.com
2. Enable **"Indexing API"**
3. Create a service account
4. Download JSON credentials
5. Use the API to request instant indexing for new pages

**When to use:**
- New high-priority campaign pages
- Breaking news/updates
- Critical fixes to existing pages

**Rate limits:**
- 200 requests/day (free tier)
- Use sparingly for important pages only
